# FizzBuzz HTML Demo

A simple interactive web page that displays "Hello, World!" and prints the classic **FizzBuzz** sequence from 1 to 100.

## Preview
- Shows "Hello, World!" as a heading.
- Displays numbers 1 to 100 with the following rules:
  - **FizzBuzz** → for numbers divisible by both 3 and 5
  - **Fizz** → for numbers divisible by 3
  - **Buzz** → for numbers divisible by 5
  - Otherwise, shows the number itself

## How to Run

1. Save the code as `index.html`
2. Open the file in any modern web browser (Chrome, Firefox, Edge, Safari, etc.)
3. No installation or server required — it runs completely offline

## Technologies Used
- HTML5
- Vanilla JavaScript (no frameworks)

## Code Features
- DOM manipulation using `document.getElementById`
- Classic FizzBuzz logic implemented with `for` loop and modulo operator
- Dynamic content generation using `innerHTML`

## Files
- `index.html` – Complete single-file implementation
